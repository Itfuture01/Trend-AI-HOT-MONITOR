# Trend AI HOT MONITOR — 需求说明

> 更新时间：2026-08-25

## 一、项目定位

一个**轻量级热点监控工具**，服务对象是 AI 编程博主。目标：不用人工手动搜索，自动发现「指定热点变化」或「最新热点」，并第一时间推送通知，让博主走在吃瓜第一线。

关键词：**轻量、敏捷、工具类、少人工介入、少工程化**。

## 二、核心功能点

### 1. 关键词监控
- 用户手动输入要监控的关键词。
- 当该关键词相关的**真实新内容**出现时，第一时间发送通知。
- 用 AI 识别「假冒内容」（标题党、营销号、同名无关、AI 造谣等），避免误报。

### 2. 热点聚合
- 每隔一段时间，自动搜集用户指定范围（如「AI 编程」）内的热点。
- 用户在网页上可查看这些热点。

## 三、产品形态

1. **响应式 Web 页面**（手机 / 桌面自适应）。
2. **Agent Skills**：封装成技能，可交给其他 AI 来监控和发现热点。

## 四、已确认的关键决策（人工确认）

| 维度 | 决策 |
|---|---|
| 通知渠道 | **浏览器实时推送 + 邮件 SMTP**（先做这两个） |
| 数据源范围 | **中英混合** |
| 关键词监控方式 | 后端直接爬网页搜索（免 API、注意频率）+ 对接 twitterapi.io 的 X/Twitter API；**多信息源并行，避免单一源** |
| 采集/信息源（8 个） | **Twitter、Bing、Google、DuckDuckGo、HackerNews、搜狗、B站、微博** |
| AI 接入 | **OpenRouter**（识别假冒内容、判断相关性、摘要） |

## 五、验收清单

- [ ] 网页响应式、视觉独特（非千篇一律）。
- [ ] 关键词命中 → 邮件 + 浏览器推送都能收到，且 AI 能拦掉明显假冒/无关内容。
- [ ] 热点聚合中英源都正常、可按范围查看。
- [ ] Agent Skill 能让另一个 AI 成功查热点 / 加关键词 / 触发扫描。

## 六、非目标（本期不做）

- 不做用户登录 / 多租户。
- 不做复杂的可视化分析平台。
- 不做历史热点趋势大屏（保留数据但只做简单展示）。
